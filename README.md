# kuailexiaohengzai

微信小游戏「再刷一下」。竖屏，一根手指滑动，全部界面画在 canvas 上。没有图片，没有 npm，没有打包步骤。用微信开发者工具直接导入这个仓库根目录。

## 导入微信开发者工具

1. 打开微信开发者工具，新建或导入时选择「小游戏」。
2. 目录选本仓库根目录（里面有 `game.js`、`game.json`、`project.config.json`）。
3. AppID：本地试玩选测试号，或沿用项目里的 `touristappid`（游客模式可以）。有自己的小游戏 AppID 再换上去。
4. 直接编译。不需要 `npm install`，也不需要构建。

`project.config.json` 里 `compileType` 是 `minigame`，`game.json` 是竖屏并且不显示状态栏。基础库写的是 `3.8.10`，工具里可以再调。

## 怎么玩

屏幕中间一张牌，上面是大箭头和「上滑 / 下滑 / 左滑 / 右滑」。在计时结束前往那个方向滑。滑对加分、连击加一，牌飞走。大约每 8 张有一张「爆款」，分数三倍。滑错或超时，这一把立刻结束。

过关之后，最大的按钮是「再刷一下」（再打刚才那一关），旁边才是「下一关」。失败界面同样是「再刷一下」。

## 存了什么

本地只有一条 JSON，键名 `zaishua-progress-v1`：

- 已解锁关卡（下一把默认从这里开始，通关后加一）
- 最高分、最高连击
- 总局数
- 最后游玩日期、连续天数

通关、这一把结束、以及切到后台（`wx.onHide`）都会写。打开游戏也会记下当天：同一天再开，连续天数不加；隔天再开加一，中间断档就从 1 重新计。回到前台继续这一把，计时不会把后台的时间算进去。

`wx.login` 拿到的 `code` 只写在本地键 `zaishua-session`，当作会话标记。没有后端，不能换成 openid。以后要用户体系，需要自己的服务器拿 code 去换。

昵称不是开门卡。右上角有个可选的「署名」（`wx.createUserInfoButton`）。玩家点了并同意，结算卡上才显示昵称。不点、接口失败、或者隐私授权被拒绝，游戏照常玩。微信已经不能静默拿昵称头像。

如果运行环境有 `wx.setUserCloudStorage`，会把最高分和最高连击写成 KV，方便以后接好友榜。游客模式或没有这个接口时会跳过，不影响本地存档。好友榜本身还要开放数据域，这次没做。

## 隐私

`game.json` 的 `officialPrivacyAuthorizationShowingGap` 是官方隐私弹窗两次出现的最小间隔（60 秒，平台下限是 10 秒）。《用户隐私保护指引》的正文要在微信公众平台后台配置，不在这个仓库里。

启动时如果存在 `wx.getPrivacySetting`，会查一下要不要授权；需要的话再调 `wx.requirePrivacyAuthorize`。这两个接口在本地模拟里没有，或者玩家拒绝，都不会拦住「点击开始」。

## 本地测试

逻辑测试不依赖微信：

```bash
node --test test/logic.test.js
```

覆盖滑动方向、关卡目标与计时曲线、存档 JSON 往返、临近失败时的文案。上传代码包时会忽略 `test/` 和 Markdown。
